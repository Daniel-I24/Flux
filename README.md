# FLUX — Asistente de notas por voz para Wear OS

FLUX se está reconstruyendo como aplicación nativa: un reloj **Wear OS** y su app **companion Android**, además de un servidor de clasificación con IA.

La versión web anterior (simulador en el navegador) está disponible en el tag [`web-simulator-v1`](https://github.com/Daniel-I24/Flux/tree/web-simulator-v1).

La documentación completa se publicará al terminar la reconstrucción.
